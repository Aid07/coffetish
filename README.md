# ТИШЬ / TISH

Сайт не открывается двойным щелчком по файлу. Его нужно запустить локальным сервером.

## Запуск

В папке проекта:

```bash
npm install
npm run dev
```

Затем откройте в браузере: **http://127.0.0.1:5173**

Интернет и Google Fonts не нужны: шрифты и фото лежат в проекте.

## Сборка

```bash
npm run build
npm run preview
```
